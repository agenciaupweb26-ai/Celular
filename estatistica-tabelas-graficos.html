frequênciatotal × 100 Futebol: 820 × 100 = 40%

O total sempre dá 100%.

Qual gráfico usar?

Barras

Para comparar quantidades. A barra mais alta é a moda.

Setores (pizza)

Para mostrar as partes de um todo. O círculo inteiro é 100%.

Linhas

Para ver como algo muda com o tempo, como a altura de uma planta.

Pictograma

Usa desenhos. Aqui, cada bola vale 2 alunos.

O que todo gráfico precisa ter

  • 1Título: diz do que o gráfico trata.
  • 2Escala: números com o mesmo espaço entre eles, começando no zero.
  • 3Categorias: o nome embaixo de cada barra.
  • 4Fonte: de onde vieram os dados.

Cuidado com gráficos enganosos!

A loja A vendeu 48 bolos e a B, 50. Com a escala começando no 46, parece que B vendeu o dobro. Começando no zero, a diferença é pequena.
